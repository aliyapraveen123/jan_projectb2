# 🚀 START HERE - AI Portfolio Generator

## Welcome! 👋

This is your **complete, production-ready AI-powered portfolio generator**!

## ⚡ Quick Start (Choose One)

### Option 1: Automated Setup (Recommended) ⭐
```bash
./setup.sh
```

### Option 2: Manual Setup
```bash
# Server
cd server
npm install
cp .env.example .env
# Add your API key to .env

# Client
cd ../client
npm install
```

## 🔑 Get Your API Key

You need either:
- **OpenAI**: https://platform.openai.com/api-keys
- **Gemini**: https://makersuite.google.com/app/apikey

Add to `server/.env`:
```env
OPENAI_API_KEY=your_key_here
```

## 🏃 Run the App

**Terminal 1 - Backend:**
```bash
cd server
npm run dev
```

**Terminal 2 - Frontend:**
```bash
cd client  
npm run dev
```

**Open**: http://localhost:5173
